Este repositorio contiene el **sitio estático ya compilado** (HTML/CSS/JS) de
**SOLE Voltaje**, servido con **GitHub Pages**. No es el código fuente: es el

conexión limitada o nula. Reúne soluciones técnicas, historias que inspiran y
un glosario, en **español, inglés y portugués**, con foco en uso
**offline-first**.
