¿Cómo instalar un servidor web en un computador de bolsillo?

Raspberry Pi: Una pequeña Internet de bolsillo.

Hola, soy Gabriel. Soy artista. Los aparatos digitales me resultan interesantes. Me considero un cacharrero y te invito a que tú también lo seas.

¿Qué es un Raspberry Pi o una Internet de bolsillo?

Esta solución te servirá para crear una pequeña internet en tu red local con pocos recursos. Al instalar un servidor, tu comunidad podrá acceder a contenidos hospedados desde sus computadores o teléfonos.

¿Para qué sirve?

Sirve para tener contenido accesible sin conexión a Internet. Por ejemplo, si vas a hacer SOLE en un lugar muy remoto. Tener contenidos descargados permitirá investigar y llegar a conclusiones sin depender de la señal externa.

¿Cómo saber si lo necesitas?

Si tu conexión a Internet es escasa o de difícil acceso, esta solución permite a las personas navegar en una réplica de algunas partes del Internet. Requiere espíritu cacharrero y paciencia.

¿Qué necesitas?

  • Raspberry Pi
  • Tarjeta MicroSD 32 GB clase 10
  • Fuente de alimentación
  • Cable de Ethernet
  • Adaptador de memoria a USB.
  • Conexión a Internet (para configurar).
  • Un computador.

¿Cómo hacerlo?

Paso 1 → Prepara tu Raspberry Pi

Los desarrolladores de Raspberry Pi han creado una herramienta llamada Raspberry Pi Imager para instalar el sistema operativo.

  1. Instala el software Raspberry Pi Imager en tu computador.
  2. Conecta la MicroSD a tu computador.
  3. Abre el programa y elige el sistema operativo para descargar.

Paso 2 → Conecta y configura tu Pi

Una vez conectada a la corriente y a tu red local, debemos ubicar su dirección IP.

  1. Usa el comando ping solevoltaje.local en tu Terminal.
  2. Conéctate por medio del protocolo SSH escribiendo ssh solevoltaje@192.168.0.25.
  3. Actualiza el software: sudo apt update && sudo apt upgrade.

Vas bien: La actualización puede tardar unos minutos. ¡Paciencia!


Paso 3 → Instala el servidor web

Vamos a instalar Nginx, un programa que permitirá que tu Pi funcione como servidor.

  1. En la terminal escribe: sudo apt install nginx.
  2. Prueba que funciona abriendo http://solevoltaje.local en tu navegador.


¿Cómo saber si esta solución funciona?

Si logras ver la página “Welcome to nginx” desde otro dispositivo en la red, ¡tu servidor local ya está funcionando!
