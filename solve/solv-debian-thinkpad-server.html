¿Cómo armar un servidor robusto con Debian en un portátil ThinkPad?

Instala Debian 13 en un portátil para crear un servidor sólido, eficiente y que nunca se duerme.

¡Hola! Soy David. He logrado mejorar la estabilidad de nuestros laboratorios SOLE a punta de prueba y error. Al principio usaba computadores con Windows o versiones pesadas de Linux, pero descubrí que para que un servidor funcione meses sin apagarse, lo mejor es usar Debian sin interfaz gráfica.

Esta guía nace de la necesidad de aprovechar portátiles potentes como los ThinkPad T480s para que sean el corazón de un SOLE Lab. No soy un experto, pero después de pelearme con la BIOS y los permisos de usuario, aquí te traigo el método que me funcionó para tener un sistema robusto.

¿Qué es un servidor robusto con Debian?

Es convertir un computador (en este caso un portátil ThinkPad) en una máquina dedicada exclusivamente a dar servicios a otros, como archivos o páginas web. Al instalar Debian 13 de forma “limpia” (sin escritorio), el equipo usa muy poca energía y RAM, dejando toda su potencia para lo que realmente importa: la comunidad.

¿Para qué sirve?

Sirve para tener un centro de información que siempre esté encendido. Al usar un portátil, tenemos una ventaja enorme: la batería funciona como un respaldo (UPS) si se va la luz. Además, al ser una instalación robusta, es mucho más difícil que el sistema se dañe o se bloquee por errores de programas visuales.

Antes de empezar…

Atención: Al instalar este sistema se borrarán todos los archivos del computador. Asegúrate de respaldar lo que necesites antes de continuar. Consejo: Para esta instalación usaremos la herramienta Medicat, que es como una navaja suiza en una memoria USB.

¿Qué necesitas?

  • Un portátil ThinkPad (o similar) con su cargador.
  • Una memoria USB con Medicat instalado.
  • Conexión a internet por cable (preferiblemente) para descargar los paquetes.
  • Curiosidad y ganas de escribir algunos comandos.

¿Cómo hacerlo?

Preparando el terreno (BIOS)

Paso 1 → Desactiva el Arranque Seguro (Secure Boot)

Los portátiles modernos traen un candado llamado Secure Boot que a veces no deja arrancar herramientas como Medicat.

  1. Reinicia el equipo y presiona repetidamente la tecla F1 (o Enter y luego F1) para entrar a la BIOS.
  2. Busca la pestaña Security y entra en Secure Boot.
  3. Cambia la opción a Disabled.
  4. Presiona F10 para guardar y salir.

Vas bien: Si al reiniciar presionas F12 y ves tu memoria USB en la lista, ya superaste el primer obstáculo.


Instalación de Debian 13

Paso 2 → Inicia el instalador gráfico

Arranca desde la USB y elige Graphical Install. Es más cómodo para configurar la red y el disco.

  1. Idioma: Elige español, pero fíjate bien que el teclado coincida con lo que ves en tus teclas (usualmente Español Latinoamericano).
  2. Red: Ponle un nombre corto al equipo (ej: sole-server).
  3. Usuarios: Aquí es clave. Te pedirá una clave de “root” (administrador) y luego crear un usuario normal.
    • Recomendamos el usuario: sole-s o soles.
    • Ejemplo de contraseña: SOLE123 (¡Pero cámbiala por una segura y guárdala bien!).

Atención: Si dejas la clave de root en blanco, tu usuario normal podrá usar el comando ‘sudo’ automáticamente. Si pones una clave de root, tendrás que configurar ‘sudo’ manualmente después (ver Paso 5).


Paso 3 → Selecciona el software (Punto Crítico)

Para que el servidor sea robusto y ligero, en la pantalla de “Selección de programas”:

  1. DESMARCA: “Debian desktop environment” y “GNOME” (no queremos escritorio).
  2. MARCA: “SSH server” (para manejarlo desde otro PC).
  3. MARCA: “Standard system utilities”.


Configuración para Portátil (Que no se duerma)

Paso 4 → Configura el cierre de la tapa

Por defecto, un portátil se apaga o se duerme al cerrar la tapa. Queremos que el servidor siga funcionando aunque esté cerrado.

  1. Entra a la terminal y escribe: sudo nano /etc/systemd/logind.conf
  2. Busca estas líneas y quítales el símbolo # al principio, dejándolas así: HandleLidSwitch=ignore HandleLidSwitchExternalPower=ignore HandleLidSwitchDocked=ignore
  3. Guarda con Ctrl+O, Enter y sal con Ctrl+X.
  4. Reinicia el servicio: sudo systemctl restart systemd-logind.

Ánimo: Si te sale “comando no encontrado”, es probable que necesites arreglar los permisos de tu usuario. Mira el siguiente paso.


Paso 5 → Arregla el comando SUDO (si es necesario)

Si al escribir sudo te dice que no se encuentra la orden, haz esto:

  1. Escribe su - y pon la clave de administrador que elegiste.
  2. Instala sudo: apt update && apt install sudo.
  3. Agrega tu usuario: usermod -aG sudo soles (cambia ‘soles’ por tu nombre de usuario).
  4. Reinicia el equipo: reboot.

Cuidado de la batería

Paso 6 → Protege la batería con TLP

Como el portátil estará conectado casi siempre, la batería puede sufrir. Instalaremos una herramienta para que no cargue siempre al 100%.

  1. Instala TLP: sudo apt update && sudo apt install tlp.
  2. Configura los límites (ej: empezar a cargar al 40% y parar al 80%): sudo tlp setcharge 40 80

Para pensar: Esto alarga la vida de tu equipo por años, evitando que la batería se infle o se dañe por calor.


¿Cómo saber si esta solución funciona?

  1. Cierra la tapa del portátil. Si puedes seguir entrando desde otro computador por SSH o si el servidor web sigue respondiendo, ¡lo lograste!
  2. El equipo debería sentirse frío y silencioso, ya que al no tener interfaz gráfica consume muy pocos recursos.

Recomendaciones

  • Usa siempre una IP fija para que sea fácil encontrar el servidor en la red.
  • Limpia el polvo del ventilador del portátil antes de dejarlo encendido 24/7.
  • Guarda las contraseñas en un papel dentro del SOLE Lab o en un gestor seguro.

Otros internets posibles

Tener un servidor robusto es como tener una biblioteca que nunca cierra. Puedes instalar una Wikipedia de bolsillo o un sistema de archivos para que los niños del SOLE guarden sus trabajos sin miedo a que se borren.
