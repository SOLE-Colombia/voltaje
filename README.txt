SOLE Voltaje — Reading without internet
=======================================

Hi! This folder is a complete offline copy of SOLE Voltaje.

HOW TO OPEN
-----------
1. Double-click "_ABRE_VOLTAJE.html"
   (or "en/index.html" to jump straight into English).
2. Your web browser will open. If you're asked which program to
   use, pick your usual browser (Chrome, Firefox, Edge, Safari...).
3. That's it — you can now browse SOLE Voltaje without internet.

WHAT WORKS OFFLINE
------------------
- Reading every note (Solve, Inspire, Glossary, Disconnected).
- Local site search.
- Switching between Spanish, English and Portuguese.
- Image gallery and bundled audios.

WHAT NEEDS INTERNET
-------------------
- YouTube/Vimeo embedded videos.
- Comments.
- Content updates.

GET A NEWER VERSION
-------------------
When you have internet, visit:
  https://voltaje.solecolombia.org

If a newer version is available, the live site shows a blue
banner at the top with a "Download" link.

VERSION YOU HAVE
----------------
See the "version.json" file (if present) or this folder's name
(voltaje-YYYY.MM.DD) to know which version you downloaded.
