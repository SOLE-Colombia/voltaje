Compartilhe sua internet de bolso

Olá, sou o Gabriel. Sou artista. Os aparelhos digitais, seu funcionamento e a forma como nós, humanos, interagimos com eles, me interessam muito. Me considero um “fuçador” (ou cacharrero, como dizemos por aqui) e te convido, se quiser, a ser um também.

Escrevi a solução Raspberry Pi: Uma pequena Internet de bolso para que você pudesse configurá-la e, agora, te acompanho para que você possa compartilhar o sinal do seu dispositivo com outras pessoas ou com outros aparelhos.

O que é compartilhar a internet do seu Raspberry Pi?

Ter um computador do tamanho de um cartão de crédito, poder conectá-lo à Internet e, além disso, poder compartilhar essa conexão com os outros computadores que você tem para fazer SOLE, é abrir as portas para a maior biblioteca do mundo!

É transformar qualquer espaço em um Ambiente de Aprendizagem Auto-Organizado, onde abrir as portas para a criatividade de solucionar os desafios, complexos ou simples, da sua comunidade é INCRÍVEL! Não é?

Para fazer SOLE, só existem três coisas fundamentais: pessoas, alguns computadores com conexão à internet e Grandes Perguntas.

Para que serve?

Com esta receita, você poderá transformar seu Raspberry Pi em um Roteador portátil, para que sua comunidade possa se conectar sem fio e acessar a informação ali hospedada e, se você contar com uma conexão à Internet cabeada, poderá compartilhá-la também.

O que você precisa?

  • Um Raspberry Pi
  • Um computador
  • Conexão à Internet - você pode conferir a solução Como saber que tipo de sinal de Internet você tem? para garantir que tipo de conexão você possui e se ela está ativa
  • Muita paciência

Como fazer?

  • Momento 1: Conecte-se ao seu Pi
  • Antes de tudo, certifique-se de ter um Raspberry Pi funcionando. Se precisar de ajuda com isso, confira a receita Raspberry Pi: Uma pequena Internet de bolso, onde contamos como começar com este dispositivo.
  • Assim que tiver seu sistema rodando, conecte-se ao seu Raspberry Pi por meio de um Terminal iniciando uma conexão SSH.
  • Certifique-se de ter conexão à Internet para poder continuar com os próximos passos.
  • Momento 2: Atualize o sistema do seu Raspberry Pi

O primeiro passo é realizar uma atualização de todo o sistema, para garantir que temos as últimas versões dos programas que rodam no nosso Pi.

Para isso, basta escrever no terminal:

sudo apt update && sudo apt upgrade

O sistema nos avisará quais pacotes devem ser atualizados. Para continuar com o processo, devemos aceitar, digitando y e pressionando a tecla enter.

  • Momento 3: Instale o software necessário

A seguir, devemos instalar dois programas no nosso Pi:

sudo apt install -y hostapd dnsmasq

Este comando instalará o hostapd, que é um utilitário que nos permite usar o wireless do nosso Pi como ponto de acesso sem fio, e o dnsmasq, que nos permitirá configurar um servidor DNS e de DHCP para permitir que usuários se conectem ao servidor e possam ter as configurações de rede necessárias para acessá-lo.

  • Momento 4: Configure um IP estático
  • Desabilitar a interface sem fio

Neste passo, configuraremos um endereço IP estático na interface sem fio do nosso Pi. É importante que você não esteja conectado via wireless ao Pi, porque durante os próximos passos a comunicação sem fio será suspensa. Então, certifique-se de estar conectado por meio de um cabo, ou ter uma tela e teclado conectados diretamente ao Pi para continuar.

As configurações de rede no Pi são gerenciadas pelo programa dhcpcd, que se encarrega de solicitar e atribuir os endereços IP necessários para as interfaces de rede disponíveis. Neste momento, temos que indicar a este programa que ignore a interface sem fio. Para isso, é preciso editar o arquivo de configuração:

sudo nano /etc/dhcpcd.conf

… e ao final dele, adicionar esta linha:

denyinterfaces wlan0

Para sair e salvar as alterações, pressionamos ctrl + x seguido de y quando perguntado.

  • Atribuir um IP estático

Agora devemos atribuir à interface wlan0 um endereço IP estático em uma faixa diferente da nossa rede cabeada. Vamos editar o arquivo:

sudo nano /etc/network/interfaces

Não tenha medo. Parece complexo, mas se você chegou até aqui, falta pouco para conseguir. Adicione o seguinte ao final:

allow-hotplug wlan0
iface wlan0 inet static
    address 192.168.10.1
    netmask 255.255.255.0
    network 192.168.10.0
    broadcast 192.168.10.255

O que estamos fazendo é configurar esta interface para ter o IP 192.168.10.1.

Para sair e salvar as alterações, pressionamos ctrl + x seguido de y quando perguntado.

  • Momento 5: Configurar nosso ponto de acesso sem fio

É o momento de indicar ao hostapd como operar. Vamos indicar que ele emita o nome da rede (SSID) e que opere em um canal específico. Colocaremos essas configurações no arquivo:

sudo nano /etc/hostapd/hostapd.conf

… onde adicionamos os seguintes dados:

interface=wlan0
driver=nl80211
ssid=SOLEVOLTAJE
hw_mode=g
channel=11
ieee80211n=1
wmm_enabled=1
ht_capab=[HT40][SHORT-GI-20][DSSS_CCK-40]
macaddr_acl=0
auth_algs=1
ignore_broadcast_ssid=0
wpa=2
wpa_key_mgmt=WPA-PSK
wpa_passphrase=LACONTRASENADEACCESO
rsn_pairwise=CCMP

Aqui você pode mudar algumas coisas:

  • O nome da rede: configuramos isso na linha ssid=. No nosso exemplo, a rede se chamará SOLEVOLTAJE.
  • O canal: channel=11 indica que vamos operar no canal 11, mas podemos mudar para o que funcionar melhor no seu local.
  • A senha de acesso: por segurança, é necessário atribuir uma chave para se conectar à rede. Fazemos isso na linha wpa_passphrase=LACONTRASENADEACCESO.

Agora devemos informar ao hostapd onde se encontra a configuração. Fazemos isso editando o arquivo:

sudo nano /etc/default/hostapd

… e adicionando nele a seguinte linha:

DAEMON_CONF=/etc/hostapd/hostapd.conf
  • Momento 6: Iniciar os serviços

Antes de reiniciar nosso Pi, devemos habilitar os serviços para que sejam executados sempre que o ligarmos.

Para isso, escreva o seguinte no terminal:

sudo systemctl unmask hostapd
sudo systemctl enable hostapd
sudo systemctl start hostapd

sudo systemctl unmask dnsmasq
sudo systemctl enable dnsmasq
sudo systemctl start dnsmasq

… e finalmente, reiniciamos o Pi para fazer nosso primeiro teste:

sudo reboot now
  • Momento 7: Faça um primeiro teste

De outro computador ou telefone, procure nas redes sem fio a rede que acabamos de criar, no nosso caso SOLEVOLTAJE, e conecte-se a ela.

Se você verificar as configurações da rede, deverá ver que o endereço IP atribuído deve estar na faixa que selecionamos na configuração do dnsmasq. No nosso caso, o dispositivo tem atribuído o IP 192.168.10.143.

  • Momento 8: Já pode compartilhar a conexão cabeada

Neste ponto, quem se conectar ao nosso ponto de acesso poderá ver os arquivos e serviços que tivermos configurados no nosso Raspberry Pi. Se você quiser compartilhar a conexão à Internet cabeada por meio da rede sem fio, continue com os próximos passos.

  • Momento 9: Encaminhar o tráfego para a conexão cabeada

É necessário que nosso sistema encaminhe o tráfego da interface sem fio para a cabeada, para poder compartilhar a conexão. Neste ponto, temos que editar o arquivo:

sudo nano /etc/sysctl.conf

No conteúdo dele, procuramos a linha que diz #net.ipv4.ip_forward=1 e removemos o # no início para indicar que queremos ativar esta diretriz. Uma vez feita essa modificação, salvamos o arquivo e continuamos com o próximo passo.

  • Momento 10: Finalmente, proteja o Firewall

Já estamos no último passo da configuração. Aqui temos que dizer ao Firewall que permita o trânsito do tráfego da rede entre as interfaces sem fio e cabeada. Para isso, inserimos estes comandos no nosso terminal:

sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
sudo iptables -A FORWARD -i eth0 -o wlan0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i wlan0 -o eth0 -j ACCEPT

Neste ponto, já deveríamos ter internet nos nossos clientes sem fio! No entanto, é preciso que essas alterações não se percam quando reiniciarmos nosso Pi. Para isso, vamos salvar a configuração em um arquivo de texto:

sudo sh -c "iptables-save > /etc/iptables.ipv4.nat"
  • Momento 11: Agora, com Internet!

Após este longo processo, os clientes conectados ao nosso Pi poderão ter acesso à conexão de Internet compartilhada a partir do nosso Raspberry Pi… CONSEGUIDO!

Se enrolou em algum dos passos? Conte-nos como completar esta solução para que ela fique mais clara.

Outras internets possíveis

Com esta receita, você pode configurar um Roteador portátil, que serve para levar conteúdos no seu Raspberry Pi e compartilhá-los com a comunidade, sem necessidade de ter uma conexão constante à Internet.

Além disso, se você tiver uma conexão cabeada, pode compartilhá-la para tornar suas sessões de SOLE mais potentes.

Por que esta solução pode funcionar?

Ter um roteador portátil e de baixo consumo nos permite levar facilmente nossos conteúdos a múltiplos lugares onde a conexão à Internet não é constante.

No entanto, o número de clientes que nosso Pi pode suportar é baixo. Se você for conectar mais de 10 pessoas ao mesmo tempo, talvez a velocidade da conexão fique um pouco lenta e, para solucionar isso, você deve buscar um roteador mais potente.

Se você chegou até aqui, aprendeu um monte de coisas que pode compartilhar com sua comunidade e, assim, melhorar as condições de conectividade. Usar a Internet em grupo é uma experiência desafiadora, tanto em termos de tecnologia quanto em termos de comunidade. Fazer SOLE é uma maneira de usar a Internet em grupo para viver melhor juntos.
