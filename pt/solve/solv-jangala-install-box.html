Como instalar um Big Box da Jangala?

Guia para colocar seu Jangala em funcionamento.

Olá! Meu nome é Catalina. Recentemente conheci as Jangala Big Box e acho que são uma solução de conectividade genial! Esta é a primeira solução que escrevo para compartilhar no Voltaje. Será curta, mas substancial; espero que seja útil para você. Vamos começar!

O que é instalar uma Jangala Big Box?

Uma Jangala Big Box é um modem muito poderoso que pode captar diferentes tipos de sinal para redistribuí-lo para até 100 pessoas.

Nesta solução, acompanho você no acesso ao manual de instalação da Big Box, no qual encontrará as instruções para vincular diferentes fontes de sinal (cartão SIM, antenas via cabo, entre outras) ao dispositivo.

Para que serve?

Para instalar você mesmo a Jangala Big Box e desfrutar da internet, em comunidade.

💬⚠️ Tenha em mente que você precisa ter uma Jangala para que esta solução seja útil. Consulte a solução “A internet em uma caixa: Big Box da Jangala” → para saber como conseguir uma Jangala Big Box.

O que você precisa?

  • Uma Jangala Big Box.
  • Um dispositivo para se conectar à internet (celular, tablet, computador ou qualquer outro).
  • Conexão com a internet.
  • Atenção.

Como fazer?

Passo 1 → Acesse a página da Jangala e escolha o manual no idioma que desejar.

Acesse a seção de instruções da página web da Jangala clicando neste link →.

Ao entrar, você verá vários botões azuis. Escolha o do idioma que preferir (espanhol?). Uma nova janela será aberta e você poderá ver as instruções.


Passo 2 → Baixe as instruções

É possível que o local onde você está consultando esta informação (boa conectividade) não seja o local onde você vai instalar sua Jangala (baixa conectividade).

Se esse for o seu caso, você pode baixar as instruções no seu celular ou computador para tê-las sempre disponíveis.

Outras internets possíveis

Se você conseguir ligar sua Jangala e conectar-se a partir de alguns dispositivos à internet, saberá que seu esforço foi um sucesso!

O que você pode alcançar com esta solução?

Colocar para funcionar uma internet poderosíssima em sua comunidade!! Não apenas porque você terá um sinal mais potente, mas porque permite que muitas pessoas acessem a internet.

O que vem a seguir é usar a internet em grupo para aprender, criar e transformar. Nas soluções relacionadas (no final deste artigo 👇🏽) recomendamos algumas soluções que poderiam ser úteis para aprender a cuidar e compartilhar equipamentos em comunidade.
