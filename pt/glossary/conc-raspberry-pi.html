Raspberry Pi

Um computadorzinho de baixo custo, perfeito para aprender e montar suas próprias engenhocas.

O que é?

Um Raspberry Pi é um computador do tamanho de um cartão de crédito que você pode configurar do seu jeito.

De cara, ele não vem com teclado, mouse ou monitor, mas você pode conectar esses e outros periféricos sem dor de cabeça nenhuma.

O “disco rígido” dele é um cartão MicroSD →, onde a gente instala uma versão do Linux → otimizada para esses dispositivos. Isso te dá um computador super portátil, que gasta pouca energia e que dá conta de quase tudo o que você faz num computador de mesa comum.

Como alimentar o seu Raspberry Pi?

Para ligar um Raspberry Pi, você precisa conectar ele a uma fonte de energia.

O jeito mais comum é usando um cabo USB para microUSB ou USB-C, dependendo do modelo, ligado a uma fonte de tomada USB. Só se liga: verifique se a fonte entrega a voltagem e a corrente certas para o seu modelo de Raspberry Pi.

Passo a passo:

  1. Identifique o conector de energia: Os modelos mais antigos, como o Raspberry Pi 3 e anteriores, usam uma porta microUSB, enquanto os modelos mais novos, como o Raspberry Pi 4 e 5, usam USB-C.
  2. Conecte a fonte: Ligue o adaptador de tomada na parede e depois conecte o cabo USB correspondente na porta do Raspberry Pi.
  3. Verifique a energia: Se estiver tudo certinho, o Raspberry Pi deve ligar. Alguns modelos têm luzinhas indicadoras que ajudam a confirmar se ele está recebendo energia.

Fique de olho:

  • Voltagem e corrente: O Raspberry Pi precisa de uma fonte de 5V. A corrente necessária varia conforme o modelo, mas geralmente a gente recomenda entre 2.5A e 3A para modelos como o Raspberry Pi 4. (Fonte: Bret).
  • Carregadores de celular: Embora alguns carregadores de celular até funcionem, o ideal é usar uma fonte feita especificamente para o Raspberry Pi. Isso garante um desempenho legal e evita problemas de energia.
  • Hubs USB: Se você precisar conectar vários dispositivos USB no Raspberry Pi, pense em usar um hub USB com alimentação própria para não sobrecarregar a placa.
  • Baterias: Se precisar alimentar o Raspberry Pi com uma bateria, não esqueça de usar um conversor DC/DC para elevar a voltagem da bateria para 5V.
  • Raspberry Pi Pico: O Raspberry Pi Pico pode ser alimentado com uma bateria externa conectada via cabo microUSB para USB.
