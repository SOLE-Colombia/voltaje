A piece of the Internet on offline computers

Install 'Endless OS' on offline computers.

📄 View video summary (Accessibility)
This video serves as a practical guide for installing "Endless OS" on offline computers, as discussed in the article. It provides a step-by-step tutorial on how to set up a functional, internet-free digital environment for educational or community use.

If you’re reading this, it’s because, like me, you’re the type who can’t sit still and loves to “tinker” with computers to make them useful for more than just typing in Word.

I’ve spent many hours battling Dual Boot installations, partitions that get wiped, and USB drives that won’t boot. That’s why I want to lend you a hand so you can take “a piece of the internet” wherever it’s needed most, without failing in the attempt. Installing Endless OS is like stuffing a giant library into an old or new computer, and here I’ll explain how to do it like a pro tinkerer.

What is this solution for?

Endless OS isn’t just a program; it’s a complete Operating System designed to work where the internet is a luxury. It comes with Wikipedia, cooking courses, health manuals, and educational games already downloaded. For a SOLE, it’s the perfect tool: it allows kids to look for answers to their Big Questions even if the router is turned off.

What do you need for this mission?

  • A computer with Windows (which is where we’ll usually be “coexisting”).
  • Internet connection (only for the initial download).
  • A USB drive of at least 32GB (if you’re going to use the memory stick method).
  • Disk space: At least 32GB free on the computer.
  • Plenty of patience and a desire to experiment.

How to do it?

1. The initial “Check-up”

Before downloading anything, check if the computer has space. In Windows, open the file explorer and make sure your “C: Drive” isn’t in the red. If you’re going to install the full version (the one with all the content), you need about 20GB to 32GB free.

Tinkerer’s tip: If the internet is really slow at the library, use a download manager like jdownloader. If the power or Wi-Fi cuts out, you won’t lose what you’ve already downloaded.

2. Download: Windows Installer or ISO Image?

If you go to the official Endless site, you’ll see two options:

  • Windows Installer: This is the easiest. It’s an .exe program that you install just like a game. It creates an automatic Dual Boot. When you turn on the PC, it will ask you: “Do you want to enter Windows or Endless?“.
  • ISO Image: This is for the more advanced folks. It allows you to create a USB that “formats” the PC or runs directly from the memory. You’ll need balenaEtcher to “burn” the ISO onto the USB. This option is good if the computer doesn’t have Windows or if you want to use Endless without touching the existing Windows installation.

3. The installation (The moment of truth)

If you use the Windows installer:

  1. Double-click the file.
  2. Select “Install alongside Windows”.
  3. Choose the “Full” version. Don’t hesitate! The basic version is like a desert without internet; the Full version is the one that comes with Wikipedia and videos.
  4. Let the PC do its thing. If it looks like it’s stuck at 99%, don’t turn it off. It’s moving heavy files.

4. The “Jump to BIOS” (If the USB doesn’t boot)

If you decided to use a USB and the computer ignores the memory and goes straight into Windows, you have to enter the BIOS/UEFI.

  • The trick: As soon as you turn on the PC, repeatedly press F2, F12, or Delete (it depends on the brand). Look for the “Boot” tab and put the USB first in the list.

Collective Glossary (To speak the same language)

As we agreed, we’ll build the meaning of these weird words we use here. If you find another one, write it down on the SOLE wall!

  • Operating System (OS): The main program that makes the computer work. Examples: Windows, Linux, Android, Endless OS.
  • Dual Boot: Having two operating systems on the same computer. When you turn it on, you choose which one to use. It’s like having a house with two doors.
  • ISO Image: A file that contains the entire operating system packaged up, ready to be “burned” onto a USB or DVD.
  • BIOS / UEFI: The most basic program on the computer that tells it what parts it has and which disk to boot from first.
  • Bootable USB: A USB drive prepared so the computer can boot (start) an operating system from it.
  • Partition: Dividing the hard drive into several “virtual” parts, as if you were putting up walls in a room so two people can live separately.

Final “Tinkerer” recommendations

  1. Update before you leave: If you already have Endless installed and still have internet, open it and let it update. Once you’re out in the field (offline), you won’t be able to download new programs easily.
  2. Test the search engine: Open the Endless search bar and type “Dinosaurs” or “Ozone layer.” If Wikipedia articles with photos pop up, you did it! You have a piece of the internet in your hands.
  3. The forum is your friend: If something goes wrong, search Google for the error followed by the words “Endless OS forum.” There’s always someone who has already gone through that problem and left the solution behind.

How far can you go? Having Endless is like having an offline library. It’s not the infinite internet of Google, but for looking up answers in a SOLE (How to do a SOLE?), it’s a thousand times better than an empty computer.
