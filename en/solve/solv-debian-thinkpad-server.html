How to build a rock-solid server with Debian on a ThinkPad laptop?

Install Debian 13 on a laptop to build a solid, efficient server that never sleeps.

Hi! I’m David. I’ve managed to improve the stability of our SOLE labs through trial and error. At first, I used computers with Windows or heavy Linux versions, but I discovered that for a server to run for months without shutting down, the best thing is to use Debian without a graphical interface.

This guide was born out of the need to take advantage of powerful laptops like the ThinkPad T480s so they can be the heart of a SOLE Lab. I’m no expert, but after wrestling with the BIOS and user permissions, here is the method that worked for me to get a robust system up and running.

What is a robust Debian server?

It’s turning a computer (in this case, a ThinkPad laptop) into a machine dedicated exclusively to providing services to others, like files or web pages. By installing a “clean” Debian 13 (no desktop), the machine uses very little power and RAM, leaving all its power for what really matters: the community.

What is it for?

It’s for having an information hub that is always on. By using a laptop, we have a huge advantage: the battery acts as a backup (UPS) if the power goes out. Plus, since it’s a robust installation, it’s much harder for the system to break or freeze due to visual program errors.

Before you start…

Heads up: Installing this system will wipe all files on the computer. Make sure to back up anything you need before continuing. Tip: For this installation, we’ll use the Medicat tool, which is like a Swiss Army knife on a USB drive.

What do you need?

  • A ThinkPad laptop (or similar) with its charger.
  • A USB drive with Medicat installed.
  • An internet connection via cable (preferably) to download packages.
  • Curiosity and a willingness to type some commands.

How to do it?

Preparing the ground (BIOS)

Step 1 → Disable Secure Boot

Modern laptops come with a lock called Secure Boot that sometimes prevents tools like Medicat from booting.

  1. Restart the machine and repeatedly press the F1 key (or Enter and then F1) to enter the BIOS.
  2. Look for the Security tab and go into Secure Boot.
  3. Change the option to Disabled.
  4. Press F10 to save and exit.

You’re on the right track: If you press F12 upon restarting and see your USB drive in the list, you’ve already cleared the first hurdle.


Installing Debian 13

Step 2 → Start the graphical installer

Boot from the USB and choose Graphical Install. It’s more comfortable for configuring the network and disk.

  1. Language: Choose English (or your preferred language), but make sure the keyboard layout matches what you see on your keys.
  2. Network: Give the machine a short name (e.g., sole-server).
  3. Users: This is key. It will ask for a “root” (administrator) password and then to create a normal user.
    • We recommend the user: sole-s or soles.
    • Password example: SOLE123 (But change it to a secure one and keep it safe!).

Heads up: If you leave the root password blank, your normal user will be able to use the ‘sudo’ command automatically. If you set a root password, you’ll have to configure ‘sudo’ manually later (see Step 5).


Step 3 → Select software (Critical Point)

For the server to be robust and lightweight, on the “Software selection” screen:

  1. UNCHECK: “Debian desktop environment” and “GNOME” (we don’t want a desktop).
  2. CHECK: “SSH server” (to manage it from another PC).
  3. CHECK: “Standard system utilities”.


Laptop configuration (Don’t let it sleep)

Step 4 → Configure lid closing

By default, a laptop shuts down or goes to sleep when you close the lid. We want the server to keep running even if it’s closed.

  1. Enter the terminal and type: sudo nano /etc/systemd/logind.conf
  2. Look for these lines and remove the # symbol at the beginning, leaving them like this: HandleLidSwitch=ignore HandleLidSwitchExternalPower=ignore HandleLidSwitchDocked=ignore
  3. Save with Ctrl+O, Enter, and exit with Ctrl+X.
  4. Restart the service: sudo systemctl restart systemd-logind.

Keep going: If you get “command not found,” you likely need to fix your user permissions. Check the next step.


Step 5 → Fix the SUDO command (if necessary)

If typing sudo tells you the command is not found, do this:

  1. Type su - and enter the administrator password you chose.
  2. Install sudo: apt update && apt install sudo.
  3. Add your user: usermod -aG sudo soles (change ‘soles’ to your username).
  4. Restart the machine: reboot.

Battery care

Step 6 → Protect the battery with TLP

Since the laptop will be plugged in almost all the time, the battery can suffer. We’ll install a tool so it doesn’t always charge to 100%.

  1. Install TLP: sudo apt update && sudo apt install tlp.
  2. Configure the limits (e.g., start charging at 40% and stop at 80%): sudo tlp setcharge 40 80

Food for thought: This extends the life of your equipment by years, preventing the battery from swelling or getting damaged by heat.


How to know if this solution works?

  1. Close the laptop lid. If you can still log in from another computer via SSH or if the web server is still responding, you nailed it!
  2. The machine should feel cool and quiet, since it consumes very few resources without a graphical interface.

Recommendations

  • Always use a static IP so it’s easy to find the server on the network.
  • Clean the dust out of the laptop fan before leaving it on 24/7.
  • Keep passwords on a piece of paper inside the SOLE Lab or in a secure password manager.

Other possible internets

Having a robust server is like having a library that never closes. You can install a Pocket Wikipedia or a file system so the kids at the SOLE can save their work without fear of it being deleted.
