How to install a web server on a pocket computer?

"Raspberry Pi: A small pocket Internet."

Hi, I’m Gabriel. I’m an artist. I find digital devices, how they work, and the way we humans interact with them quite interesting. I consider myself a bit of a tinkerer—a cacharrero—and I invite you, if you’d like, to be one too.

What is a Raspberry Pi, or a pocket-sized Internet?

This solution will help you create a small internet on your local network with very few resources.

By installing and configuring a server on the network, your community will be able to access the content hosted on it from their computers or phones. This way, you can have, for example, a copy of Wikipedia so everyone can check it whenever they need to, without needing to access the Internet to do so.

What is it for?

If we’re talking about using the Internet to solve Big Questions and real-life challenges as a group, having content accessible without an Internet connection can be an excellent option: for example, if you are going to do a SOLE session in a very remote place where you know connectivity definitely won’t be viable.

Having downloadable content available offline will allow them to research and reach some conclusions, which they can expand upon later when they have an Internet connection or when they can connect an “Abuelita” (a cloud-based learning hub).

Do you want to know more about how to turn your space into a place for learning, or who the “Abuelitas de la Nube” are? Visit Solecolombia.org to learn how, and browse the site to find out more about the Nube de Abuelitas that can support the learning processes happening in your space.

How do you know if you need it?

Ask yourself how good your Internet connection is in the place where you’ll be connecting. At SOLE Colombia, we know the difficulties of many remote communities where the internet is scarce or hard to access, and a solution like this allows people to access downloaded content, which is almost like having access to their twins on the web.

This way, it becomes possible to browse a replica of parts of the Internet, learning to use technology in a different way.

Even though its benefits are many and obvious, this is a solution that requires a powerful spirit of tinkering and high doses of commitment and patience… we are sure you can manage to set up your own little pocket internet!

What do you need?

  • Raspberry Pi
  • 32 GB Class 10 MicroSD card
  • Power supply for the Raspberry Pi - check the specifications on Raspberry Pi
  • Ethernet cable
  • MicroSD to USB memory adapter.
  • Case for RPI (optional)
  • Internet connection
  • A computer
  • Patience

How to do it?

Below are the steps to get your server up and running:

Step 1 → Prepare your Raspberry Pi

For this solution, we are using a Raspberry Pi v4, but previous versions should work without any issues.

If you are starting with a new Raspberry Pi and have a plastic case, assemble the heat sink on the RPI processor and place it inside its protective case before continuing.

The Raspberry Pi developers have created a tool to facilitate the downloading, installation, and configuration of the MicroSD cards that will hold the operating system the RPI runs on.

  • Install the specific software for your operating system, Raspberry Pi Imager

To install it on your computer, visit https://www.raspberrypi.com/software/. There, you can download the version of Raspberry Pi Imager that works on your operating system (Windows, Linux, or Mac). Once you install it, you can continue with the next step.

  • Connect the MicroSD to your computer

Before running the Raspberry Pi Imager, you must connect the MicroSD memory card to your computer.

To do this, you need to use a USB adapter if your device doesn’t have a slot for it.

Once you verify that the memory is detected by the computer, run the Raspberry Pi Imager and continue with the solution.

  • Open the Raspberry Pi Imager and choose your operating system


Step 2 → Connect and configure your Pi

  • Locate it in the Pi Imager

Now that our Pi is connected to power and our local network, we need to locate it so we can connect to it.

Before this, a small note: we will perform the following steps using a Terminal. If you use a Unix-type operating system (Linux, MacOS), simply search for the terminal and you can follow the steps there (see below for how to do it). If you use Windows, you can use CMD for this step, and to connect to the Pi, you can use Putty.

To locate the Pi in a Terminal, we use the ping program. This will try to send a small data packet to the address we indicate and will tell us, among other things, the IP address of the computer.

Here we will use the name we gave our Pi, in our case solevoltaje. In the terminal, we type ping solevoltaje.local. The program responds, among other things, with the IP 192.168.0.25, which indicates that our Pi is available for us to connect and start working.

  • Connect to the Pi

For the connection between your Pi and other devices to be secure, we connect to our Pi via the SSH protocol. To do this, we type ssh solevoltaje@solevoltaje.local or use the IP address ssh solevoltaje@192.168.0.25 in our terminal.

Remember that we must place our username and domain name or IP in the parameters we provide to SSH: ssh <username>@<domain name>.

As soon as the connection is established, the system will ask for the password. Type the same one you entered during the configuration in the previous steps and finish by pressing the enter key.

  • Update the software

Once we are connected to the Pi, we must perform a couple of administrative tasks. The first is to update our operating system’s software. We do this by typing the following in the terminal:

sudo apt update && sudo apt upgrade

Once the task of downloading and configuring the new software is finished, we can continue with the solution.

The commands we enter in this line start with sudo to have superuser permissions and be able to apply changes to the system.

  • Expand the SWAP

Now, it is necessary to expand the SWAP memory space so our Pi can easily handle operations that require more memory than what we have available in the RAM Memory. Perform the following steps one after another:

First, deactivate the SWAP memory:

sudo dphys-swapfile swapoff

Then, edit the configuration file and change the size to our needs:

sudo nano /etc/dphys-swapfile

In the file, look for the line that says CONF_SWAPSIZE=100 by default and change it to CONF_SWAPSIZE=2048. Then, save and exit the text editor.

Now we need to activate the new configuration:

sudo dphys-swapfile setup

Reactivate the SWAP memory:

sudo dphys-swapfile swapon

Finally, restart the Pi so all programs have access to the new SWAP:

sudo reboot

This last command restarts the Pi, closing our remote connection. You must wait a couple of minutes for the process to complete and then reconnect via the SSH protocol to continue.

  • Now, install the server

After all this preparatory process, which is simpler than it seems, we proceed to install nginx, a program that will allow our Pi to function as a web server, so we can access resources hosted there from other devices using a web browser.

Once we are connected to the Pi, we type in the terminal:

sudo apt install nginx

This line downloads, installs, and starts our server.


Step 3 → Test that the server is working correctly

Now, we test that everything is working.

To do this, on our computer, we open a web browser window and in the address bar, we type http://solevoltaje.local

If everything is working correctly, we should see a page like the one in the image that says Welcome to nginx.

How do you know if this solution works?

With this solution, you will manage to have a local server that allows you to host content that will be visible on the local network.

This way, you can download useful material for SOLE sessions and not need Internet access to answer the Big Questions. You can also think about loading content you would like to take to a remote place or share with other people, for example, movies, educational material, instructions, online games… or anything you can download to use with others!

Thanks to the fact that the Pi is so small, you can take it to different places and have a pocket-sized Internet.
